# تطبيق IPTV مجاني (نسخة أولية - Android)

مشروع Android Studio جاهز (Kotlin + Media3 ExoPlayer) لتشغيل قنوات بث مباشر (HLS/M3U8) من مصادر **مجانية ومتاحة للعموم (Free-to-air)** فقط.

## المزايا المُنفذة في هذه النسخة
- قائمة قنوات ثابتة (من ملف `assets/channels.json`)
- تصنيف حسب الفئة (رقاقات Chips قابلة للنقر)
- بحث فوري عن القنوات
- مفضلة (تُحفظ محليًا عبر SharedPreferences)
- مشغل فيديو HLS بشاشة كاملة (ExoPlayer / Media3)

## ⚠️ مهم قبل التشغيل
روابط البث الموجودة حاليًا في `app/src/main/assets/channels.json` هي **أمثلة توضيحية فقط** لقنوات معروفة بأنها مجانية ومتاحة للعموم رسميًا (الجزيرة، فرانس24، سكاي نيوز عربية، BBC News، Red Bull TV). لكن:

1. روابط البث الفعلية (m3u8) لهذه القنوات **تتغيّر بشكل متكرر** من الجهة الناشرة نفسها، لذا يجب عليك التحقق من صلاحية كل رابط وتحديثه.
2. **المصدر الموصى به للحصول على روابط محدّثة وقانونية دائمًا**: مشروع [iptv-org](https://github.com/iptv-org/iptv) المفتوح المصدر، والذي يحدّث الروابط تلقائيًا يوميًا. يمكنك:
   - إما استبدال محتوى `channels.json` بروابط محدّثة يدويًا من هناك.
   - أو (الأفضل لاحقًا) جعل التطبيق يجلب قائمة القنوات ديناميكيًا من رابط مباشر مثل:
     ```
     https://iptv-org.github.io/iptv/countries/sa.m3u
     ```
     بدل تخزينها ثابتة داخل التطبيق — هذا يضمن أن الروابط تبقى صالحة دون تحديث التطبيق نفسه.
3. لا تضف أي قناة مدفوعة أو محمية بحقوق نشر بدون ترخيص رسمي من الناشر.

## طريقة الفتح والتشغيل
1. افتح **Android Studio** (نسخة Hedgehog أو أحدث يفضّل).
2. اختر `Open` ثم حدد مجلد المشروع `IPTVApp`.
3. اترك Gradle يزامن التبعيات تلقائيًا (يحتاج اتصال إنترنت).
4. اضغط `Run` على جهاز حقيقي أو محاكي (Emulator).

## البنية
```
app/src/main/java/com/iptvapp/free/
  ├── data/        # نموذج القناة + تحميل JSON + المفضلة
  ├── ui/          # الشاشة الرئيسية + المحول (Adapter)
  └── player/      # شاشة تشغيل الفيديو (ExoPlayer)
app/src/main/assets/channels.json   # قائمة القنوات الثابتة
```

## الخطوات التالية المقترحة
- جلب القنوات ديناميكيًا من رابط m3u حي بدل الملف الثابت.
- تحويل الأيقونة الافتراضية إلى أيقونة مخصصة عبر أداة Image Asset في Android Studio.
- إضافة Android TV support (يحتاج تصميم واجهة Leanback منفصلة).
- لوحة تحكم عن بُعد لإدارة القنوات دون تحديث التطبيق (لاحقًا حسب رغبتك).
